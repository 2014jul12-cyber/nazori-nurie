# なぞってぬりえ

2〜3歳向けの、なぞり絵とぬりえ。GitHub Pagesで公開すると、Chromeで開けて、ホーム画面に追加すればオフラインでも使えます。

## 公開のしかた
1. GitHubで新しいリポジトリを作る(例: `nazori-nurie`)。
2. このフォルダの中身(index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png)をリポジトリの直下にアップロードする。
3. Settings → Pages → Branch を `main` / `(root)` にして Save。
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける。

## オフラインで使うには
- 1回だけ、通信できる状態で開く(Android Chrome: メニュー → 「ホーム画面に追加」または「アプリをインストール」)。
- 以降は通信なしでも開けます。

## 更新したとき
index.html を差し替えたら、sw.js の `VERSION` を `v2` のように1つ上げてください。上げないと、古い版が表示され続けることがあります。

## 保存されるもの
描いた絵と、なぞった結果の履歴は、その端末のブラウザの中だけに保存されます。ブラウザの「サイトデータを削除」をすると消えます。
